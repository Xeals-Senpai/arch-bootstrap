# Documentation

This directory contains supporting documentation for `arch-bootstrap`.

## Available Documentation

### WORKFLOW.md

Documents the internal architecture and execution flow of the bootstrap framework, including:

* Runtime workflow
* Module responsibilities
* Profile system
* Package categories
* Dotfile deployment process
* User configuration
* Testing procedures
* Development notes

## Project Status

The bootstrap framework has been validated on a real Arch Linux installation.

Current functionality includes:

- Pacman package installation
- AUR package installation
- Dotfile deployment
- Font configuration
- Zsh and Starship configuration
- Desktop environment setup
- Git configuration
- Profile-based installation

Documentation will continue to evolve alongside future improvements and new features.
